# VSPO! HUB WIDGET // Desktop Archive

「ぶいすぽっ！」コスプレイヤーさんの美しいアーカイブ写真を、あなたのデスクトップに。
Webサイト [VSPO! HUB] と連携し、常に最新の「推し」を表示し続ける専用ウィジェットです。

---

## ✨ 主な機能
- **自動同期**: サイトで設定した「推しメン」や「テーマカラー」が、そのままアプリに反映されます。
- **デスクトップ常駐**: ブラウザを開かなくても、いつでも壁紙感覚で写真を楽しめます。
- **軽量動作**: パソコンの動作を邪魔しないよう、非常に軽い設計になっています。

## 📥 導入方法 (Windows専用)
現在は Windows 10 / 11 (64bit) に対応しています。

1. **ダウンロード**: [配布ページ](https://vspo-cosplay.vercel.app/download) からインストーラー（.exe）をダウンロードしてください。
2. **インストール**: ダウンロードしたファイルをダブルクリックして実行します。
3. **ログイン**: アプリを起動し、サイトと同じIDでログインすれば同期開始です！

## ⚠️ 起動時に警告画面が出た場合
個人開発のアプリであるため、Windowsによって「PCが保護されました」という青い画面が出ることがあります。以下の手順で安全に実行できます。

1. 画面内の **「詳細情報」** をクリック。
2. 右下に現れる **「実行」** ボタンを押すとインストールが始まります。
*※この警告は、マイクロソフトに登録されていない個人アプリであるために表示されるもので、ウイルス等の心配はありません。*
